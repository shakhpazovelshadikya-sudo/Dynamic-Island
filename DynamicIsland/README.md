# Dynamic Island для Windows (C# / WPF)

Требования: Windows 10 (1809+) / Windows 11 и .NET 8 SDK.

## Запуск
    dotnet run

## Сборка в exe
    dotnet publish -c Release -r win-x64 --self-contained false -o publish

Файл publish/DynamicIsland.exe можно положить в автозагрузку (Win+R -> shell:startup).

## Установщик (DinamicIslandsetap.exe)
1. Ничего ставить заранее не нужно: если нет .NET 8 SDK или Inno Setup 6, bat сам их скачает и установит.
2. Запусти `build-installer.bat` — он опубликует приложение (без встроенного .NET — установщик около 5 МБ) и соберёт `installer\Output\DinamicIslandsetap.exe`. Если на ПК пользователя нет .NET 8 Desktop Runtime, установщик сам скачает и поставит его.
3. В `installer\Output` лежат `DinamicIslandsetap.exe` (установщик) и `DynamicIsland.exe` (portable, без установки). Без Windows можно собрать через GitHub Actions (`.github/workflows/build.yml`).
4. Мастер установки: выбор папки (по умолчанию `C:\DynamicIsland`), группа в «Пуске», галочки «ярлык на рабочем столе», «ярлык в меню Пуск», «запускать вместе с Windows» и «запустить после установки». Права администратора не нужны.
4. Установщик добавляет ярлык в меню «Пуск» (и на рабочий стол по желанию), а при удалении убирает автозапуск и останавливает процесс.
Настройки и полка в `%AppData%\DynamicIsland` при удалении не трогаются.

## Что умеет
- Капсула сверху по центру экрана, поверх всех окон, не видна в Alt+Tab
- В покое показывает время (или ♪ трек, если что-то играет); слева в капсуле всегда виден текущий язык ввода (RU, EN и т. д.)
- Если название трека не помещается, капсула и остров плавно расширяются (пределы — в настройках → «Размер»); не влезло даже в предел — текст медленно прокручивается (бегущая строка: пауза, прокрутка до конца, пауза, возврат)
- Наведи курсор — капсула плавно превращается в прямоугольный остров с разделами (вкладки-иконки сверху: 🏠 главная, ☁ погода, 📅 календарь, 📁 полка, ⏰ таймер, 📋 буфер обмена, ⏻ система; название — в подсказке при наведении):
  - **Главная** — обложка (в капсуле при воспроизведении тоже), название, исполнитель, кнопки prev/play/next, полоска прогресса с перемоткой (клик или перетаскивание), общая громкость Windows ползунком и кнопкой «без звука», кнопка-название плеера для выбора, время и заряд батареи
  - **Календарь** — текущая дата, номер недели и сетка месяца (Пн–Вс, выходные подсвечены, сегодня выделено); стрелки листают месяцы, клик по названию — возврат к текущему
  - **Полка** — перетащи файл или программу и запускай одним кликом
  - **Погода** — температура, ощущаемая, ветер, влажность, мин/макс на сегодня и прогноз на 3 дня
- При смене трека сама раскрывается на 3 секунды
- ПКМ по острову — «Выход»
- Иконка в трее: двойной клик — скрыть/показать остров; меню — «Запускать вместе с Windows» и «Выход»
- Автозапуск включается сам при первом запуске собранного exe (реестр HKCU\...\Run), отключить можно в меню трея.
  При запуске через `dotnet run` автозапуск не регистрируется — только для опубликованного exe

## Плеер на главной
- **Перемотка:** кликни или потяни полоску прогресса. Работает, если плеер сообщает длину трека и разрешает перемотку (Spotify, Яндекс Музыка, браузеры с YouTube — обычно да; для прямых эфиров полоска неактивна и показывает «live»). Цвет полоски берётся из обложки.
- **Громкость:** ползунок справа внизу меняет общую громкость Windows (устройство вывода по умолчанию), значок динамика — «без звука».
- **Выбор плеера:** кнопка с названием плеера (например «Spotify ▾») открывает список всех плееров, которые видит Windows; ▶ — тот, что играет. Можно закрепить нужный или вернуть «Авто».
- **Обложка:** в большом виде на главной и маленькой в капсуле, пока играет музыка. Если плеер не отдаёт обложку, показывается значок ♫.

## Система
Вкладка ⏻ — быстрые настройки и питание:
- **Wi-Fi и Bluetooth** — плитки-переключатели (светлая плитка = включено). Управляют радиомодулями через API Windows, права администратора не нужны. ПКМ — открыть параметры Windows.
- **VPN** — включает и выключает встроенные VPN-профили Windows (через `rasdial`; в профиле должны быть сохранены логин и пароль). ПКМ по плитке — выбрать профиль, если их несколько. Если профилей нет, клик открывает параметры VPN. Сторонние клиенты (WireGuard, OpenVPN и др.) не управляются.
- **Блокировка, сон** — выполняются сразу. **Рестарт и выключение** — с подтверждением: первый клик меняет подпись на «Точно?», второй в течение 3 секунд выполняет команду. Программы с несохранёнными данными сами спросят, закрывать ли их.
- **Громкость** — «−», «без звука», «+» (медиаклавиши, шаг 10%). Состояние показывает стандартный индикатор Windows.
Состояние переключателей обновляется раз в 5 секунд, пока вкладка открыта.

## Таймер
Вкладка ⏰: пресеты 1/5/10/25 минут запускают отсчёт сразу, кнопки «−1 / +1 мин» меняют время (до 180 минут; на ходу — оставшееся), ▶/⏸ — старт и пауза, ↻ — сброс.
Пока таймер идёт, в капсуле вместо времени показывается «⏱ 04:32» (на паузе — «⏸»). Когда время выйдет, играет системный звук и под островом появляется карточка.

## Буфер обмена
Вкладка 📋 хранит последние 25 скопированных **текстов** (картинки и файлы не сохраняются). Клик по записи возвращает её в буфер, ПКМ — «Копировать», «Удалить», «Очистить всё».
История хранится только в памяти (на диск не пишется) и стирается при выходе. Записи, помеченные менеджерами паролей как «не для истории», пропускаются.
Выключить можно в настройках → «Остров» → «История буфера обмена» (история при этом стирается).

## Переводчик
Вкладка 🌐: слева вводишь или вставляешь текст, справа появляется перевод (через 0,7 с после паузы в наборе или по Ctrl+Enter). Языки выбираются кнопками сверху (более 45 языков, у исходного есть «Определить язык»), ⇄ меняет их местами. «Вставить» берёт текст из буфера, «Копировать» кладёт перевод в буфер. Выбранные языки запоминаются. Нужен интернет (бесплатный сервис Google Translate без ключа), за один раз переводятся первые 1800 символов.
Остров не забирает фокус, поэтому при клике в поле ввода он ненадолго становится активным окном, чтобы можно было печатать, и сам сворачивается, когда вы закончили. Если вкладки нет — включите её в настройках → «Вкладки» (при обновлении старый список вкладок сохраняется).

## Полка
Вкладка «Полка» — быстрый запуск файлов и программ. Перетащи на остров exe, ярлык, папку или любой файл
(остров сам раскроется на полке). Клик по плитке запускает элемент, ПКМ — «Открыть», «Показать в папке», «Убрать с полки».
Колесо мыши листает полку. Хранятся только пути к файлам (копий нет): `%AppData%\DynamicIsland\shelf.json`, до 30 элементов.
Если файл удалён или перемещён, при клике он уберётся с полки.

## Журнал ошибок
Ошибки (погода, медиа, уведомления, полка и т. д.) и необработанные исключения пишутся в `%AppData%\DynamicIsland\log.txt`.
Открыть: трей → «Открыть журнал ошибок» или настройки → «О программе». Когда файл больше 512 КБ, старый уходит в `log.old.txt`.
Одинаковые ошибки чаще раза в минуту не повторяются. Если что-то не работает — пришли этот файл.

## Структура проекта
`MainWindow` разбит на частичные файлы — по одному на вкладку или задачу:

| Файл | Что внутри |
|---|---|
| `MainWindow.xaml.cs` | конструктор, позиция окна, анимации раскрытия/сворачивания, мышь, настройки, `UpdateUi` |
| `MainWindow.Layout.cs` | динамическая ширина капсулы и острова под длинный текст |
| `MainWindow.Pet.cs` | питомец в капсуле: настроения и анимация |
| `MainWindow.Marquee.cs` | бегущая строка для названий, не влезающих даже в максимальную ширину |
| `MainWindow.Tabs.cs` | переключение вкладок, порядок и видимость из настроек |
| `MainWindow.Media.cs` | вкладка «Главная»: обложка, прогресс, громкость, выбор плеера |
| `MainWindow.Weather.cs`, `Calendar.cs`, `Shelf.cs`, `Timer.cs`, `Clipboard.cs`, `System.cs` | остальные вкладки (батарея — в `System.cs`) |
| `MainWindow.Language.cs` | анимация смены раскладки «EN → RU» |
| `MainWindow.Fullscreen.cs` | скрытие острова при полноэкранном окне |
| `MainWindow.Toasts.cs` | карточки уведомлений под островом |

Папка `Script/` — весь код (окна, сервисы и помощники (настройки, полка, таймер, буфер, трей, автозапуск, журнал…).
`Script/api/` — всё, что обращается к внешним источникам: `MediaService` (плееры Windows), `WeatherService` (интернет), `NotificationService` (база уведомлений), `VolumeService` (Core Audio), `SystemService` (Wi-Fi, Bluetooth, VPN).

## Питомцы
Настройки → «Питомец»: кот, собака, слайм или кролик (или никого). Питомец живёт в левой части капсулы (капсула из-за него чуть шире) — пиксель-арт 12×12, анимирован кадрами:
- **сидит** — моргает и виляет хвостом;
- **гуляет** — переступает туда-сюда;
- **спит** — над ним плывут «z»; чем дольше нет активности (наведения мыши, смены трека), тем чаще он засыпает;
- **пританцовывает**, пока играет музыка;
- **подпрыгивает** при смене трека, когда остров свернулся обратно и после уведомления (заодно будит спящего).
Когда остров раскрыт или показывает уведомление, анимация не тратит ресурсы. Спрайты лежат в `Script/PetSprites.cs` — чтобы добавить своего питомца, допиши запись в `PetSprites.All` (палитра и 10 кадров); тесты проверят размеры и цвета.

## Тесты
Проект `DynamicIsland.Tests` (xUnit) лежит рядом с `DynamicIsland`. Запуск из корня репозитория:

    dotnet test DynamicIsland.Tests

Покрыто: таймер, полка, настройки, список вкладок и расчёт ширины острова. Тесты не трогают настоящий `%AppData%`.

## Настройка
Отступ сверху, пределы ширины, порядок и видимость вкладок меняются в окне настроек (см. ниже).
Базовые размеры (160×34 в покое, 460×178 раскрытым) — константы `CompactBaseW`, `CompactH`, `ExpandedBaseW`, `ExpandedH` в начале `MainWindow.xaml.cs`.

## Язык интерфейса
Настройки → «Основные» → «Язык острова»: Авто (по языку Windows), Русский или English. Язык применяется после перезапуска — остров предложит перезапуститься сразу после сохранения. Тексты лежат в `Script/Loc.cs` (ключ — русская фраза), чтобы добавить язык, достаточно ещё одного словаря.

## Обновления
Остров раз в 30 минут (и при запуске) смотрит последний релиз на GitHub. Если версия новее — показывает уведомление и кнопку «⬆ Обновить» на раскрытом острове; в Настройки → «О программе» тоже появляется «Обновить до X» (если обновлений нет — кнопки нет, есть только «Проверить обновления»). Нажатие скачивает `DinamicIslandsetap.exe` из релиза и тихо ставит поверх.
Чтобы выпустить обновление: подними версию и запушь тег, например `git tag v1.1.0 && git push origin v1.1.0` — GitHub Actions соберёт установщик и сам создаст релиз.

## Смена языка
При переключении раскладки клавиатуры капсула на секунду расширяется и показывает «EN → RU» (новый язык выкатывается снизу). Включается в настройках → «Остров».

## Уведомления
Сообщения из других приложений (мессенджеры, почта и т.д.) показывает сама капсула: она на несколько секунд расширяется до скруглённого прямоугольника с иконкой приложения, названием, заголовком и текстом, а потом сжимается обратно. Клик закрывает уведомление, наведение курсора задерживает. Если остров в этот момент раскрыт (или раскрывается), уведомление выезжает обычной карточкой под ним. Несколько уведомлений идут по очереди. Включить/выключить и посмотреть пример можно в настройках → «Уведомления».
Как это работает: обычное приложение (не MSIX) не может подписаться на уведомления официальным способом,
поэтому остров читает базу уведомлений Windows (`%LocalAppData%\Microsoft\Windows\Notifications\wpndatabase.db`)
в режиме «только чтение» — копию, ничего не меняя. Разрешения и установка не нужны.
Это недокументированный способ: после крупных обновлений Windows он может перестать работать.
Текущий способ и состояние (работает / не работает и почему) видны в настройках → «Уведомления» → «Состояние». Если базы нет, остров проверяет её раз в 30 секунд.
Обычные баннеры Windows при этом остаются — отключить их можно в Параметрах Windows → Система → Уведомления.

## Настройки
Шестерёнка ⚙ в правом верхнем углу острова (или трей -> «Настройки…») открывает отдельное окно:
- отступ острова от верхнего края
- «Размер»: максимальная ширина капсулы (200–420 px, по умолчанию 380) и раскрытого острова (460–800 px, по умолчанию 640) — до этих пределов остров растягивается под длинное название трека
- «Вкладки»: какие вкладки показывать и в каком порядке (кнопки ▲ ▼); «Главная» отключить нельзя. Скрытая «Полка» не принимает перетаскиваемые файлы
- раскрытие при смене трека (вкл/выкл)
- анимация смены языка (вкл/выкл)
- история буфера обмена (вкл/выкл)
- показ уведомлений (вкл/выкл) и кнопка «Показать пример»
- монитор, на котором показывается остров (кнопка «Сменить» переключает по кругу; если монитор отключён — остров уходит на основной)
- скрывать остров в полноэкранном режиме (игры, видео, F11 в браузере; по умолчанию выключено; учитывается только монитор острова)
- автозапуск вместе с Windows

Хранятся в `%AppData%\DynamicIsland\settings.json`.
